# Move() — Movimentando o Drone

O comando `move()` é utilizado para movimentar o Drone pela fazenda.

Para utilizar o comando, precisamos informar para qual direção o Drone
deve se movimentar.

# Move para o Norte
move(North)

# Move para o Leste
move(East)

# Move para o Sul
move(South)

# Move para o Oeste
move(West)

move()       → movimenta o Drone
North        → Norte
South        → Sul
East         → Leste
West         → Oeste
